## Project Covers
- 5 years of P&L, Balance Sheet & Cash Flow analysis (FY21–25)
- FY26 & FY27 forecasting using Assumption-Based Growth Rate & Common Size method
- Interactive 3-page Power BI dashboard with dynamic KPIs, ratio analysis & year-wise slicers

## Tools & Skills
- Microsoft Excel — data structuring & forecasting
- Power Query — data cleaning & transformation
- Power BI — interactive dashboard design
- DAX — custom KPI & measure creation
- Financial Statement Analysis — P&L, Balance Sheet, Cash Flow
